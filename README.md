# Telegram-бот для подбора онлайн-курсов по кулинарии

## Описание
Бот помогает пользователю подобрать курс по кулинарии с помощью опроса, а затем оформить заявку. Заявка автоматически отправляется менеджеру в Telegram.

## Стек
- Python 3.10+
- python-telegram-bot
- python-dotenv
- httpx

## Установка

1. Клонируйте проект.
2. Создайте виртуальное окружение:
```bash
python -m venv venv
```
3. Активируйте окружение.

Windows:
```bash
venv\Scripts\activate
```

Linux/macOS:
```bash
source venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Создайте файл `.env` на основе `.env.example`.

6. Запустите бота:
```bash
python bot.py
```

## Возможности
- Подбор курса по уровню, кухне и формату обучения.
- Поддержка произвольной кухни.
- Оформление заявки.
- Отправка заявки менеджеру в Telegram.
- Поддержка работы через VPN/прокси.

## Структура проекта
- `bot.py` — основной код бота.
- `courses.json` — база курсов.
- `.env` — секретные настройки.
